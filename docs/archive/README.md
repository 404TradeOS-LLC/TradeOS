# Archived Documentation

This directory preserves historical planning, audit, and handoff material.

Rules:

- do not use these files as implementation truth
- prefer the authoritative files listed in `docs/README.md`
- keep archived files for historical context only

The binary planning artifacts in this directory are preserved intentionally because they informed earlier phases, but they are not authoritative for RC1 implementation work.

## Visual/UI design archives

Historical visual and UI design artifacts live under `docs/archive/design-sources/`. They are preserved only for provenance and must never be used as current visual authority. The sole active TradeOS visual/UI design authority is https://www.figma.com/file/xImUa9CYUjx3Cb3zTrkfnY?type=design.
