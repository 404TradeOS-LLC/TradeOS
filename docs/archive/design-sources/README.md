# Archived TradeOS visual/UI design sources

**Status: historical and non-authoritative.**

The sole active visual/UI design authority for TradeOS is the canonical Figma file:

https://www.figma.com/file/xImUa9CYUjx3Cb3zTrkfnY?type=design

File key: `xImUa9CYUjx3Cb3zTrkfnY`

Nothing in this directory may be used as current authority for visual hierarchy, page composition, component appearance, responsive layout, interaction states, color/typography choices, or product-screen design.

These files are retained only for provenance and historical comparison. Before any TradeOS UI design, audit, or implementation work, open the canonical Figma file and inspect the actual target page and current frames.

Capability/domain documents still govern what TradeOS is allowed to do. Current production code and CSS still govern exact runtime behavior and accessibility. Neither is a competing visual design source.

Historical branch-only sources are preserved outside the active product tree on:

- `archive/design-system-legacy-2026-09-29`
- `archive/canonical-design-doc-legacy-2026-09-29`

Those branches are archival evidence only and must never be used as current visual guidance.
